# Top-Level LVS Reports

Per-cell LVS run folders of `chip_top`, written by `make klayout-lvs` (`chip_top.klayout.lvs/`) and by `make magic-lvs` (`chip_top.magic.lvs/`). Both folders are wiped at the start of each run, so they always reflect the latest run only.

The top-level LVS is not implemented on `main` yet, so this folder is still empty. The work in progress lives on the [`top-level-lvs`](https://github.com/iic-jku/ihp-sg13g2-ams-chip-template/tree/top-level-lvs) branch and gets merged once it runs through. See [Layout Versus Schematic (LVS)](../../README.md#layout-versus-schematic-lvs) in the top-level README.
